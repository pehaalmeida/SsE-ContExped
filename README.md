# SsE-ContExped

**SsE-ContExped** é um software desenvolvido para gerenciar a saída de cargas e pedidos no setor de expedição de caminhões. Ele proporciona controle preciso dos veículos que entram e saem, bem como o registro de informações relevantes para o setor de expedição.

## 🎯 Objetivo

O principal objetivo deste sistema é facilitar a rotina logística da expedição, garantindo:

- Registro eficiente das saídas de caminhões.
- Controle de entrada e saída de veículos.
- Registro dos valores associados à carga ou pedido.
- Melhoria no fluxo de informações entre os setores logísticos e administrativos.

## 🚚 Funcionalidades

- Cadastro e controle de motoristas.
- Registro de cargas e pedidos em tempo real.
- Armazenamento de dados para consulta e relatórios.
- Interface intuitiva e de fácil operação.

## 🛠️ Tecnologias Utilizadas

- **C#** com Windows Forms
- **.NET Framework**
- Sistema de arquivos e configuração com `.config`
- Projeto estruturado com Visual Studio (`.sln`)
